# swarm-maker
Stat generator for making swarms according to the method of the dungeon-coach (https://www.youtube.com/c/TheDungeonCoach).  

The tool uses the ([dnd5eapi.co](https://www.dnd5eapi.co/))  
  
The tool is not perfect, it works best for monsters between CR 0-1/2 with swarms of 50-100. 
But you can tinker with the inputs as you like. The tool might receive some additional updates to improve the generation for different types of monsters.
## Running
In general I recommend you to compile the source code yourself instead, you should not download random executables from the internet (I can merely promise that they are safe). 
## Running on linux
Download the linux version in the releases page (https://github.com/SangzorDeGeit/swarm-maker/releases/) and make the file executable.

## Running on Windows
Download the windows version in the releases page (https://github.com/SangzorDeGeit/swarm-maker/releases/) and double click it, windows will probably give a warning, I can only promise that the executable is safe, but you should not trust random programs on the internet.
